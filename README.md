# SMS-Spam-Classifier
A Machine Learning project that classifies SMS/Email messages as Spam or Not Spam using Python, NLP, TF-IDF, and Machine Learning.

🛠️ Technologies
Python
Pandas & NumPy
NLTK
Scikit-learn
TF-IDF
Streamlit
🔄 Workflow

Data → Preprocessing → NLP → TF-IDF → ML Model → Spam/Not Spam

✨ Features
Spam message detection
Text preprocessing
TF-IDF vectorization
Machine Learning prediction
Streamlit web application
▶️ Run Project
pip install -r requirements.txt
streamlit run app.py
